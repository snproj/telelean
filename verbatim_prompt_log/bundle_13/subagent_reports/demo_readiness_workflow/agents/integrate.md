## how_to_run
**Live demo through the driver (main session only; spends subscription quota)**

Run it from the main session's own Bash tool with run_in_background: true. That shell runs inside the snap VS Code (AppArmor snap.code.code), which bwrap needs on this kernel; a plain terminal or ssh would be refused at the preflight. Run it when the Spyro live walkthrough is not running: the driver cancels at the first rate-limit status that is not 'allowed', and only one heavy process should run at a time. Check `free -m` first.

```
cd /home/zhengyew/telelean && ulimit -c 0 && env -u TELELEAN_NO_REAL_CLAUDE TELELEAN_DEMO_LIVE=yes node packages/extension/scripts/demo-driver.mjs --live --vscode snap --work-dir /tmp/claude-1002/-home-zhengyew-telelean/03a29d54-7342-40e3-b5f0-2697a62c93ef/scratchpad/turn13/live-demo-1 --assume "All humans are mortal" --assume "Socrates is a human" --goal "Socrates is mortal" > /tmp/claude-1002/-home-zhengyew-telelean/03a29d54-7342-40e3-b5f0-2697a62c93ef/scratchpad/turn13/live-demo-1.json 2> /tmp/claude-1002/-home-zhengyew-telelean/03a29d54-7342-40e3-b5f0-2697a62c93ef/scratchpad/turn13/live-demo-1.log
```

- **Exit code:** 0 = the demo reached its end as expected, 1 = it did not, 2 = refused or a setup error.
- **Progress:** in the .log file.
- **Results:** in live-demo-1/summary.json:
  - passed and result;
  - each round's verdict, gap, gate attempts, statements and new vocabulary;
  - the questions with the answers given, and Claude's guesses (answered[]);
  - adopted premises and the statuses after Accept;
  - finalLean, usage (tokens and cost estimate) and the transcript path;
  - problems and realHomeChanges.
- **Screenshots:** live-demo-1/screenshots/.
- **Each run needs a new --work-dir** (live-demo-2, …).

**Variants**
- The user's own example: 1–4 `--assume "…"` plus one `--goal "…"`, one line each, distinct.
- `--answer 1|2|3|4|open|decide|text:WORDS`, one per question in order (default: option 1); `--answer-scope run|nodes|subject`.
- A not-proved example, to see a suggested premise adopted: `--assume "Socrates is a human" --goal "Socrates is mortal"`. Add `--no-adopt` to stop at not proved.
- Speed and limits: `--effort medium` (faster; the default is the extension's high), `--model M`, `--timeout-minutes N` (default 60).
- `--show` watches the window on DISPLAY :0; otherwise it runs headless under xvfb.
- `--continue-on-rate-warning` if the shared plan already shows a warning.

**What a live run touches:** the real HOME. Claude Code reads its login from ~/.claude/.credentials.json and writes its usual session files (~/.claude/projects/…, ~/.claude.json). The VS Code instance resolves the user's login-shell environment (`--force-user-env`, as the snap's desktop file does). VS Code's profile, XDG folders and the snap's SNAP_USER_DATA stay in the work dir.
