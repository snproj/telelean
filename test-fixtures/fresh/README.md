# fresh-model fixtures (turn 13, the demo path)

FakeBackend scripts in which a well-behaved Claude follows the system prompt on a **fresh** model: an empty folder
after "telelean: Initialize Model Here" (runner `inspectFolder` + `planInitialize`), with the person's own example
typed on the board as cards (M1 `add-node` actions: code-less blocks in `Model/Demo/Inbox.lean`). Claude has to
create everything itself: sorts, propositions, predicates, constants with their existence presupposition
(`axiom T.exists : Nonempty T` + `instance : Nonempty T := T.exists`), the statements below the cards' blocks, the
selected assumptions' `.holds`, lemmas and proofs. Used by `packages/runner/test/run/fresh.e2e.test.ts` (real
RunManager, Lean check engine with sandboxed Lean, proposal service, Accept, a refresh and the board's statuses).
Nothing here is ever compiled: Lean text appears only inside JSON strings.

## Format

The walkthrough format (`../walkthrough/README.md`: `turns`, `steps`, `answer`, `adopt`, `expect`), plus what the
test needs to build the fresh model:

- `subject` (always `Demo`) and `today`: the date the board writes into `asserted:` (the test fixes the workspace's
  clock to it, so the scripts' edits can quote the blocks exactly);
- `cards`: the cards typed in the A|D|G box, in order, each `{ type, naturalName, id }`; `id` is the id the board
  derives (the test checks it, since the edits rely on it);
- `target`, `premises`: what the person selects before pressing "These suffice" (the start declares the premises on
  the target's block, so the target's block gains a `premises:` line before Claude reads it);
- `after` (only `plato.json`): the script runs in the model where the named script's proposal was accepted.

`expect` holds `verdict` (or `round1`/`round2` for an adoption), `definitions` (the names of the definition
questions: only each new sort's `T.exists`), `footprint` (the report card's), and optionally `selfEvident`,
`failedChecks` and `freezeRefusals` (mistakes a script makes on purpose and repairs), `ghostNode`, `ghostStatement`.
